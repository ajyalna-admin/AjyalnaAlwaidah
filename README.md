# موقع مبادرة أجيالنا الواعدة

موقع مبني بـ Next.js 15، React 19، TypeScript، Tailwind CSS، وFramer Motion. الموقع عربي فصيح بالكامل (RTL).

## التشغيل محليًا

```bash
npm install
npm run dev
```

بعدها افتحي http://localhost:3000

## النشر على Vercel

```bash
npm install -g vercel
vercel
vercel --prod
```

## ⚠️ هذا المحتوى مسودة أولية

كل النصوص مسودة كتبتها بناءً على المعلومات المتوفرة عن المبادرة، ولازم تُراجَع وتُعدَّل قبل النشر النهائي. كل المحتوى موجود في ملف واحد: `lib/data.ts` — هذا هو المكان الوحيد الذي تحتاجين التعديل فيه لتغيير أي نص في الموقع.

### أهم ما يحتاج تعديلًا

1. **الهيكلة التنظيمية** (`structure` في `lib/data.ts`): ثماني لجان إرشادية وست لجان فرعية، كل لجنة فيها حقلا "القائدة" و"النائبة" بقيم مؤقتة ("اسم القائدة" / "اسم النائبة"). استبدليها بالأسماء الفعلية.
2. **قائمة التميز** (`excellenceList`): أضيفي اسم كل لجنة وأسماء العضوات المتميزات فيها. يمكن إضافة أو حذف لجان بحرية من المصفوفة.
3. **الموارد والمواضيع** (`resourceFiles`): قسم مخصص لمشاركة الملفات مع الطالبات المستجدات. **لإضافة ملف حقيقي:**
   - ضعي الملف داخل مجلد `public/files/` (مثلًا: `public/files/دليل-التسجيل.pdf`)
   - أضيفي بياناته في مصفوفة `resourceFiles` بهذا الشكل:
     ```ts
     {
       title: "عنوان الموضوع",
       description: "وصف مختصر للموضوع",
       fileUrl: "/files/دليل-التسجيل.pdf",
       fileType: "PDF",
     }
     ```
   - العناصر الثلاثة الحالية أمثلة توضيحية فقط وروابطها غير فعّالة، استبدليها بملفاتكم الفعلية.
4. **قسم "أثرنا"** (`impact`): الأرقام حاليًا أصفار مع تنبيه واضح بالموقع. حدّثيها بالأرقام الحقيقية قبل النشر، أو احذفي القسم إذا لم تتوفر بيانات بعد.
5. **فريق المبادرة** (`team`): فيه حاليًا ريناد كقائدة وعضوتان بأسماء مؤقتة — أكملي بأسماء الفريق الفعلي.
6. **قنوات التواصل** (`brand`): البريد الإلكتروني وحسابات إنستغرام وتويتر جميعها أمثلة، استبدليها بالحسابات الفعلية.

## الهوية البصرية

- الخلفية: كريمي دافئ (`#F5F2ED`)
- اللون الأساسي: كحلي غامق (`#121F3E`) — نفس لون الشعار
- لون التمييز: أزرق فاتح مستخرج من هوية المبادرة (`#9DB9C8`)
- الخط: Cairo للعناوين، Tajawal للنصوص
- الشعار (`public/logo.png`) وصورة الهيدر (`public/hero-photo.jpg`) مأخوذة من ملفات الهوية المرفوعة، وتمت معالجتها (إزالة خلفية الشعار، وقص الصورة).

## البنية

- `lib/data.ts` — مصدر كل النصوص والبيانات
- `components/` — قسم واحد لكل جزء من الصفحة
- `app/page.tsx` — الصفحة الرئيسية التي تجمع كل الأقسام بالترتيب: الرئيسية، من نحن، أهدافنا، الهيكلة، برامجنا، الموارد، التميز، أثرنا، الفريق، تواصل معنا
